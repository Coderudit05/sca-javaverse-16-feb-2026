# SCA Javaverse - HTML and CSS Foundations

A topic-based collection of HTML and CSS examples for learning the building blocks of web development. The repository is organized as a sequence of small, editable examples suitable for classroom demonstrations and independent revision.

## Current Topics

- Types of CSS: inline, internal, and external stylesheets
- The CSS cascade
- CSS selectors
- Additional HTML and CSS fundamentals organized into topic folders

## Run the Examples

No package installation is required.

```bash
git clone https://github.com/Coderudit05/sca-javaverse-16-feb-2026.git
cd sca-javaverse-16-feb-2026
```

Open an HTML file from the `html/` or `css/` folder in a browser. VS Code Live Server is optional but useful for editing and previewing examples.

## Recommended Workflow

1. Start with the types-of-CSS examples.
2. Compare inline, internal, and external styling.
3. Continue through the selector examples.
4. Change one rule at a time and observe which elements are affected.
5. Practice by rebuilding each example from scratch.

## Learning Goals

- Understand how HTML and CSS work together
- Compare different ways to apply styles
- Select elements using common CSS selectors
- Learn through small, focused examples
